# Juego de la Vida de Conway

Programa realizado en Python basado en el Juego de la Vida de Conway.

El programa simula la evolución de una cuadrícula de células siguiendo las reglas establecidas para este autómata celular. En cada generación, el estado de las células cambia dependiendo de las células que se encuentran a su alrededor.

**Tecnologías utilizadas**

Python

**Funcionamiento**

El programa genera un estado inicial para el tablero y posteriormente calcula las siguientes generaciones aplicando las reglas del Juego de la Vida.

**Configuración**

Es necesario tener Python instalado para ejecutar el programa.
